# Folio

随手记下生活里的细节，需要时找得到。

Folio 计划做一款私人生活记录应用，用文字、照片和声音留下那些容易忘记的小事：一家店值得再点的菜、旧照片背后的经历、护照放在哪个抽屉，或一件旧物的来历。

## 当前进度

项目处于需求评审与设计探索阶段，尚未开始应用开发，也没有可安装或运行的版本。

首版功能范围、目标平台、技术栈和最终界面方案仍待确定。需求文档中的功能提案与视觉概念不代表已经实现或确定上线。

## 已确定的方向

- 随手记录、随手保存，支持多种媒体形式，方便分类和找回。
- 第一版优先做好离线体验，不依赖联网完成基础使用。
- 第一版不包含 AI 功能；图片文字识别、录音转文字和自然语言找回已保留，后续由用户选择使用。
- 从基础功能逐步迭代，功能增加时保持统一的视觉风格与交互逻辑。

## 首版候选

首版建议先把记录、保存和找回做完整。以下为候选范围概览，各条目的确认情况以需求文档为准：

| 方面 | 候选内容 |
|---|---|
| 记录 | 文字、照片、应用内录音及其组合；草稿恢复与后续补充 |
| 整理 | 可选标签、星标与置顶；日期和手动填写的地点等线索 |
| 找回 | 时间流、文字搜索、时间与媒体类型过滤 |
| 数据保护 | 删除撤销、回收站；可读导出仍待审核 |
| 使用体验 | 无账户即可开始记录，明确的保存反馈 |

首版文字搜索的候选范围是正文、标签和手动填写的说明等，不包含照片里的文字或录音中说的话。

复制记录、自定义模板、记录合并与拆分、个人图章标签、感受刻度、状态标记和情境组合标签已确认保留能力，具体上线版本待安排。

当前先实现基础功能。完整备份与恢复、单条私密放到后续；字体调整、减少动效、手势的按钮替代和完整的空白与失败状态，在功能开发后完善。应用锁与备份提醒暂缓，已确认的保存反馈和草稿恢复仍属于基础能力。

自由整理、星标与置顶、人物物件线索及别名、记录关联、时间浏览、搜索和组合筛选已确认保留。引导式找回保留为后续探索；记录成组与可选专题页也已保留，具体上线批次待定。独立文件夹系统暂缓，当前通过标签、记录组与可选专题页组织内容。

地点与时间能力已完成本轮去留审核；感受标签支持自由命名、多种感受并存、可选程度和常用搭配。生活切片、心情天气、安慰小事和声音标本并入已有能力，不再独立安排。

首版特色候选包括“地点星图”“轻量生活章节”和“照片陈列柜”，也可以先不选特色。地点列表与地点页是否进入首版仍待确认；真实地图后续保留，具体地图选型另行讨论，路过提醒暂缓。完整 3D 展厅仍属于后续规划。

## 空间、时间与物件

正在探索用三个角度浏览同一批记录，形成统一的产品体验：

| 主题 | 关注什么 | 示例 |
|---|---|---|
| 生活地图 | 我和地方的关系 | 在一家店留下的菜品照片、口味备注与再次到访的记录 |
| 生活片段 | 一段日子里的经历 | 把“毕业那个夏天”的照片与声音放进同一章节 |
| 私人收藏 | 物件的来历和陪伴 | 为外婆的搪瓷杯留下照片、展签与经历，逐步探索立体陈列 |

这些是待审核的组织方式，不是首版必须同时上线的三个模块。普通记录也可以一直保持简单，不必先分类、建章节或放进展馆。
