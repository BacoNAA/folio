# Folio

随手记下生活里的细节，需要时找得到。

Folio 计划做一款私人生活记录应用，用文字、照片和声音留下那些容易忘记的小事：一家店值得再点的菜、旧照片背后的经历、护照放在哪个抽屉，或一件旧物的来历。

## 当前进度

项目处于需求评审与设计探索阶段，尚未开始应用开发，也没有可安装或运行的版本。

已按[整体需求审查](docs/requirements/整体需求审查.md)整理正文、子操作、共同规则和前置关系，并将已确认的功能边界写入正文。剩余范围与已确认结论索引集中见[待确认问题](docs/requirements/待确认问题.md)。

目标平台、技术栈、首版范围和最终界面方案仍待确定。需求文档中的阶段建议与视觉概念不代表已经实现或确定上线。

## 已确定的方向

- 随手记录、随手保存，支持多种媒体形式，方便分类和找回。
- 第一版优先做好离线体验，不依赖联网完成基础使用。
- 第一版不包含 AI；识别、转写和自然语言找回留到后续，由用户选择使用。
- 先明确功能范围，再按必要性、难度与依赖安排多个开发迭代，每轮形成可使用的能力，保持统一的视觉风格与交互逻辑。

## 当前能力与分期

| 方面 | 已确认方向 |
|---|---|
| 记录 | 自由文字、照片、基础声音、多媒体组合、完整内容草稿与完成后更新 |
| 整理 | 标签、星标、置顶、对象与记录状态、记录关联、记录组及其可选导览 |
| 找回 | 时间流、文字搜索、具体对象限定、组合筛选及人物物件线索 |
| 空间 | 地点命名与复用、可选坐标、地点列表与小册、地点体验、星图及后续地图 |
| 时间 | 双时间、模糊时间、生活章节、回看、对照与变化 |
| 数据保护 | 删除撤销与回收站；单条私密、完整备份与恢复后置 |

照片记录、基础声音、保存反馈、草稿恢复与编辑补充已明确首版保留。具体开发迭代留待后续统一安排；其他标为“首版建议”“后续建议”或“待定”的能力继续分别确定批次，见[版本规划](docs/requirements/版本规划与审核事项.md)。

清单、照片标注、复制、模板、合并拆分、个人图章、感受刻度、状态标记和情境组合均已保留，范围与版本继续细化。同一项信息在模板与标记中共用。

当前优先基础能力。字体、动效、操作替代和完整状态体验后续完善；应用锁与备份提醒等暂缓。首版特色仍可选地点星图、轻量章节或先不选特色；选择时一同确认其最小前置范围。收藏展示以记录组和导览为基础，3D 保留为后续呈现探索，独立建模等额外能力另议。
