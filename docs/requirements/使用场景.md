# 使用场景

[返回需求总索引](../Folio-需求与设计文档-v0.1.md)

以下例子说明已有能力怎样配合。场景名称与内容只是使用示例，具体版本以所用能力的最终安排为准。

## 一道好吃的菜

在小馆子吃到一道喜欢的菜，拍照并写下“微辣刚好，下次试豆花”，附上地点后保存。几个月后搜索菜名，或者从地点列表打开相关记录，就能找到当时的照片与说明。

相关能力：[文字记录](A-记录与保存.md#r002-文字记录)、[照片](A-记录与保存.md#r003-照片记录)、[地点](C-地点与空间.md#r013-手动填写地点)、[文字搜索](B-整理关联与查找.md#r024-文字搜索)、[地点小册](C-地点与空间.md#r033-地点页)。

## 补记一段旧日子

翻到大学毕业时的照片，把事件时间写为“2016 年夏”，用照片、文字和声音补充那段经历。内容按事件时间浏览，也能从最近添加的记录中找到。需要整理时，可以把相关记录放进一个组，或在章节能力上线后收进“毕业那个夏天”。

相关能力：[组合记录](A-记录与保存.md#r005-组合记录)、[双时间](D-时间章节与回看.md#r011-事件时间与记录时间分开)、[模糊时间](D-时间章节与回看.md#r012-模糊时间)、[记录成组](B-整理关联与查找.md#r102-记录成组)、[生活章节](D-时间章节与回看.md#r042-轻量生活章节)。

## 一只杯子和一本护照

把“护照在书房第二个抽屉”写成一条普通记录并置顶。给外婆的杯子留下照片和来历，以后又有相关经历时再记一条，并关联到同一个物件；需要时按物件集中找回。也可以用记录组整理自己想一起看的内容。

相关能力：[文字记录](A-记录与保存.md#r002-文字记录)、[照片](A-记录与保存.md#r003-照片记录)、[星标与置顶](B-整理关联与查找.md#r022-星标与置顶)、[人物物件线索](B-整理关联与查找.md#r015-人物与物件线索)、[记录成组](B-整理关联与查找.md#r102-记录成组)。
