# 使用场景

[返回需求总索引](../Folio-需求与设计文档-v0.1.md)

三个例子帮助理解不同能力如何配合。文中版本描述是候选演示，是否上线以各项需求的审核结果为准；场景中的操作写法不代表界面已定稿。

## 场景一：一道好吃的菜

周五晚上，您在一家小馆子吃到很好的酸菜鱼。您打开 Folio，拍一张照片，写下“微辣刚好，鱼片嫩，下次试豆花”，地点栏输入“巷口川菜”，点保存，屏幕提示“已保存在这台设备上”。整个过程不需要选类别。三个月后朋友问哪里的酸菜鱼好吃，您搜索“酸菜鱼”，或者打开地点列表里的“巷口川菜”，就能看到这条，以及上次和同事去时记下的另一道菜。
（首版：[R002](A-记录与保存.md#r002-文字记录)、[R003](A-记录与保存.md#r003-照片记录)、[R006](A-记录与保存.md#r006-有内容就能保存)、[R013](C-地点与空间.md#r013-手动填写地点)、[R024](B-整理关联与查找.md#r024-文字搜索)、[R032](C-地点与空间.md#r032-地点列表)、[R033](C-地点与空间.md#r033-地点页)。以后可以加上 [R034](C-地点与空间.md#r034-口味刻度) 口味刻度、[R035](C-地点与空间.md#r035-下次想试) 下次想试、[R036](C-地点与空间.md#r036-地图底图) 地图。）

## 场景二：补记一段旧日子

一个周末，您翻到大学毕业那年夏天的旧照片。新建记录时打开“这是以前的事”，事件时间填“2016 年夏”，导入三张照片，再录一段现在的自己讲当时的宿舍。您新建章节“毕业那个夏天”，把它放进去。时间流里，它出现在“2016 年夏”的位置，而不是今天；在章节里，3 条记录就已经是完整的一章。
（首版基础：[R011](D-时间章节与回看.md#r011-事件时间与记录时间分开)、[R012](D-时间章节与回看.md#r012-模糊时间)、[R004](A-记录与保存.md#r004-原始录音)。只有选 [R042](D-时间章节与回看.md#r042-轻量生活章节) 为首版特色时才有章节；否则这些内容先作为普通记录保存。以后可以加上 [R046](D-时间章节与回看.md#r046-时间缩放) 时间缩放、[R048](D-时间章节与回看.md#r048-生活切片) 生活切片。）

## 场景三：一只杯子和一本护照

您把“护照在书房书架第二个抽屉”记成一条普通记录并置顶，需要时一眼就能看到，不必做别的。外婆留下的搪瓷杯则不同：以后的版本里，您可以把它放进收藏，从三个角度拍照，写一句“外婆每天用它喝茶”，展签的其他项都空着，再附上一段以前保存的外婆说话声；若声音来自外部文件，需要 [R090](A-记录与保存.md#r090-导入已有录音)。假设杯子后来不慎摔碎，您可以主动移入告别展区，并在履历里记下这件事，系统不自动判断它的状态。
（首版：[R002](A-记录与保存.md#r002-文字记录)、[R022](B-整理关联与查找.md#r022-星标与置顶)。以后：[R057](F-物件管理与私人收藏.md#r057-自愿放进收藏)、[R069](G-陈列展馆与内容输出.md#r069-多角度换帧)、[R063](G-陈列展馆与内容输出.md#r063-展签)、[R051](D-时间章节与回看.md#r051-声音标本)、[R060](F-物件管理与私人收藏.md#r060-物件履历)、[R062](F-物件管理与私人收藏.md#r062-告别展区)。）
