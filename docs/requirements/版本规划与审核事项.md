# 版本规划与审核事项

本文汇总分期建议、首版候选检查项和待决定问题。具体能力、阶段与审核状态以各类 R 条目为准；确认保留不等于确认进入首版。

## 分期建议

以下安排不代表时间承诺。

| 阶段 | 重点 | 主要条目 |

| 首版候选 | 把保存和找回做完整，再选一个少量内容也能体验的特色 | [R001](A-记录与保存.md#r001-打开即用不需要账户)—[R016](B-整理关联与查找.md#r016-同名不自动合并)、[R018](B-整理关联与查找.md#r018-引用而不是复制)、[R020](B-整理关联与查找.md#r020-可以永远不归属)—[R025](B-整理关联与查找.md#r025-时间与类型过滤)、[R027](H-隐私与数据保护.md#r027-删除后可立即撤销)—[R028](H-隐私与数据保护.md#r028-回收站)、[R032](C-地点与空间.md#r032-地点列表)—[R033](C-地点与空间.md#r033-地点页)、[R073](I-全局界面与交互.md#r073-大字与清晰对比)—[R077](H-隐私与数据保护.md#r077-隐私锁)、[R079](H-隐私与数据保护.md#r079-完整备份)—[R081](G-陈列展馆与内容输出.md#r081-可读导出)、[R083](H-隐私与数据保护.md#r083-备份提醒)；特色候选 [R042](D-时间章节与回看.md#r042-轻量生活章节) 或 [R068](G-陈列展馆与内容输出.md#r068-照片陈列柜) |
| 第二阶段 | 完善空间、时间和关联 | 手动跨记录关联及纠错，视频、文件、链接，地图，口味刻度，回顾类功能，人物入口，单条私密与便捷入口 |
| 第三阶段 | 收藏与展馆 | 图鉴、物件、特展、展签、换帧、立体展厅、小志 |

首版刻意不做人物和物件大模块、复杂的时间缩放和回信。历年同日这类回顾功能可以利用导入的旧照片，但首版的价值不能建立在“用了很多年之后”。

这张表是审核候选清单，不是一次全部实现的承诺。[R026](B-整理关联与查找.md#r026-引导式找回) 属于探索，不在首版范围。选 [R042](D-时间章节与回看.md#r042-轻量生活章节) 时才有章节入口及过滤；选 [R068](G-陈列展馆与内容输出.md#r068-照片陈列柜) 时带上其最小加入、移出、排序和列表操作。两种特色的备份与验收随选择生效，也可以决定两者暂缓。

新增 [R091](A-记录与保存.md#r091-清单记录) 清单记录、[R092](A-记录与保存.md#r092-照片绘制与标注) 照片绘制与标注已确认保留能力，上线版本尚未决定，暂不并入任何阶段。

[R094](A-记录与保存.md#r094-自定义记录模板)—[R099](B-整理关联与查找.md#r099-自定义状态标记) 与 [R101](B-整理关联与查找.md#r101-情境组合标签) 已确认保留，分别为自定义模板、记录合并与拆分、个人图章标签、自定义感受刻度、自定义状态标记和情境组合标签，上线版本待安排。[R093](A-记录与保存.md#r093-复制记录) 独立复制记录仍待审核；[R100](B-整理关联与查找.md#r100-声音记号) 声音记号暂缓，留作后续探索。

[R007](A-记录与保存.md#r007-清楚的保存反馈) 本机保存反馈、[R008](A-记录与保存.md#r008-草稿与中断恢复) 草稿与中断恢复、[R009](A-记录与保存.md#r009-编辑与补充) 编辑与补充已确认首版保留。[R010](A-记录与保存.md#r010-权限被拒也能记录) 先实现记录方式可独立使用的基础能力。当前优先确认和实现主要功能，复杂异常处理、详细权限引导等保护性措施后续细化；这不撤销已确认的草稿恢复等基础能力。换手机与数据迁移暂不纳入本轮讨论，备份、恢复与导出等独立条目仍待审核。

[R090](A-记录与保存.md#r090-导入已有录音) 已有录音导入已确认保留能力，仍列为后续建议，具体上线版本待确认。[R085](J-后续AI能力.md#r085-录音转文字) 录音转文字继续待审核，不因确认导入能力而自动纳入范围。

## 首版完成检查

以下项目尚未测试，待版本范围确定后用于验收。

以下为候选检查清单，是否执行以功能的最终版本范围为准。当前先确认核心能力，保护性措施的详细验收后续细化。

- 未登录、飞行模式下，能完成第一条记录的保存。
- 只拍一张照片、什么字都不写，也能保存。
- 拒绝麦克风权限后，仍然能记文字和使用其他不依赖麦克风的记录方式。
- 录音时切换应用或遇到中断，回来后能恢复已成功保存的草稿和声音片段，未保存部分有明确提示。
- 补记旧事时，事件时间不会自动变成今天；“2016 年夏”能正常保存和过滤。
- 两个同名人物不会被自动合并。
- 搜索能搜到说明文字，界面写明无法搜索录音和照片里的内容。
- 删除后能撤销，也能从回收站恢复。
- 选择章节特色时，同一记录在章节和地点下引用，修改一处，两处都更新；章节可以重叠。
- 选择陈列柜特色时，能选封面、排序、点开和移出；移出不删除原记录，文字或录音记录也能展示。
- 从完整备份恢复到兼容的干净测试环境后，媒体、已启用功能的关联与排列完整。
- 损坏备份或恢复空间不足时，原有记录仍可用；不会先清空再报告失败。
- 可读导出只包含选中的记录。
- 开启大字号和减少动效后，所有操作仍然可以完成。
- 所选特色在只有 3 条记录的章节，或空展柜、单件陈列时仍正常、体面；未选择的功能不作为首版验收要求。

## 待决定问题

- **Q01** 首版特色选轻量章节（[R042](D-时间章节与回看.md#r042-轻量生活章节)）、照片陈列柜（[R068](G-陈列展馆与内容输出.md#r068-照片陈列柜)），还是两者都暂缓？
- **Q02** 使用平台：手机为主是否成立？先做哪个系统？
- **Q03** 首页是以记录流为主，还是突出三个主题入口？[产品原则 P08](产品方向与原则.md#视觉与交互原则后置讨论) 建议先从记录流开始。
- **Q04** 付费方式是否在本阶段讨论，还是先保留未定？
- **Q05** 补记旧事的“以前的事”开关（[R011](D-时间章节与回看.md#r011-事件时间与记录时间分开)）是否合适？
- **Q06** 地点列表与地点页（[R032](C-地点与空间.md#r032-地点列表)、[R033](C-地点与空间.md#r033-地点页)）是否放进首版？
- **Q07** 回收站希望保留多久？备份提醒是否只在打开应用时出现？
- **Q08** 隐私范围怎样取舍：仅应用锁、增加单条私密、完整备份增加密码保护？可以分别给出首版或后续意见。
