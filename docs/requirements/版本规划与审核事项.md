# 版本规划与审核事项

[返回需求总索引](../Folio-需求与设计文档-v0.1.md)

本文保存现行能力的分期方向和验收范围。具体内容与确认状态以各能力正文为准；生活场景只用于举例。未决范围集中在[待确认问题](待确认问题.md)。

## 迭代安排方式

核心功能边界、九条产品原则及下述五方面首版内容均已确认，首个目标平台为安卓（Android）。技术选型、开发难度评估与迭代安排留待后续。后续结合必要性、实现难度与最小前置划分多个开发迭代；每轮交付可以完整使用和验证的能力，逐步增加功能并保持统一设计。

首版所含能力可以经过多轮开发逐步完成。下表维护已确认的首版范围及后续方向；具体迭代数量、顺序与每轮范围后续统一安排，不将全部已保留需求集中到一个版本实现。

## 首版范围（已确认）

2026-11-02 确认以下五方面首版内容。功能正文及具体边界仍在所属能力文件维护，本表不新增需求编号。首版无需账户，安装后可离线记录、保存、查看和找回。

| 方面 | 首版范围 | 正文入口 |
|---|---|---|
| 记录内容与维护 | 自由文字、照片、基础录音、基础清单，可单独使用、自由组合与继续追加；包括保存反馈、完整已支持内容的草稿恢复及完成后统一更新 | [A 记录与保存](A-记录与保存.md) |
| 基础整理 | 自定义文字标签、星标、置顶，以及地点、人物和物件的基础线索；整理不是保存前提 | [B 整理关联与查找](B-整理关联与查找.md) |
| 浏览与查找 | 时间流、事件时间与记录时间、模糊时间、文字搜索，以及时间、文字标签、媒体类型、星标和已支持的具体对象条件的组合筛选 | [B 浏览与找回](B-整理关联与查找.md#b5-浏览与找回)、[D 时间基础](D-时间章节与回看.md#d1-时间表达与共同规则) |
| 基础地点浏览 | 地点命名与复用、可选坐标、地点列表和基础地点小册；从地点查看关联记录并打开原记录 | [C 地点与空间](C-地点与空间.md) |
| 删除与恢复 | 删除后立即撤销、回收站及记录恢复，恢复已支持内容与仍有效的关系；保留期限和清理规则随设计确认 | [H 删除与恢复](H-隐私与数据保护.md#h1-删除与恢复) |

地点星图、真实地图、生活章节、记录组及可选导览安排在后续。照片标注、复制、模板、合并拆分等本轮未决定批次的增强，不列入此次确认的首版范围；继续按各条阶段细化。

## 后续与待定安排

已确认后置的内容继续保留，具体后续版本与日期待定。下表区分本轮确认的后续安排、沿用的后续建议与仍待定的批次。

| 阶段 | 重点 | 范围 |
|---|---|---|
| 后续（已确认） | 扩展媒体、标记与主题体验 | 视频、文件、链接、已有音频导入、个人图章、刻度、状态、情境组合、地点星图、真实地图、生活章节、记录组及可选导览 |
| 后续建议 | 扩展关联及回看 | 记录直接关联与纠错、地点体验、时间分层浏览、同日与季节回看、未来胶囊、照片对照、变化、颜色与随机回看 |
| 上线批次待定 | 按完整用途细化增强 | 照片标注、复制、模板、合并拆分、地点待办及人物物件小册；本轮未纳入已确认首版范围 |
| 后续数据保护 | 基础功能完成后安排 | [单条私密](H-隐私与数据保护.md#r078-单条私密记录)、[完整备份](H-隐私与数据保护.md#r079-完整备份)、[从备份恢复](H-隐私与数据保护.md#r080-从备份恢复) |
| 后续体验完善 | 功能开发后统一完善 | 字号与清晰对比、手势的按钮替代、减少动效、完整空白与失败状态 |
| 后续 AI | 可选择的识别与找回增强 | 图片文字识别、录音转文字、自然语言找回及用户控制规则；全部不进入首版 |
| 暂缓 | 当前不安排 | 应用锁、备份提醒、独立文件夹系统、接收其他应用分享、声音记号和路过提醒 |

[照片记录](A-记录与保存.md#r003-照片记录)、[基础声音](A-记录与保存.md#r005-组合记录)、[保存反馈](A-记录与保存.md#r007-清楚的保存反馈)、[草稿恢复](A-记录与保存.md#r008-草稿与中断恢复)和[编辑补充](A-记录与保存.md#r009-编辑与补充)沿用此前已确认的首版范围。基础声音包含应用内录制、停止、试听与播放、单段删除和继续添加；后台长录音与剪辑后续另行安排，首版不做转写。已有音频导入安排后续。

新建记录编辑中自动保存草稿，点“完成”后才进入正式记录流与搜索。草稿覆盖已支持的文字、照片、已录好并成功保存的声音，以及清单、地点和标签等已填写内容。修改已有记录时，完成前保留上一次完成的内容供浏览和找回，未完成修改可继续或放弃，具体规则见 R008、R009。

[模板](A-记录与保存.md#r094-自定义记录模板)和[刻度](B-整理关联与查找.md#r098-自定义感受刻度)、[状态](B-整理关联与查找.md#r099-自定义状态标记)共用同一项信息；复制、合并、拆分各自的内容结果、时间和引用规则已明确，见[共同规则](A-记录与保存.md#复制合并与拆分的共同规则)，具体设计细节随对应迭代细化。

[记录成组](B-整理关联与查找.md#r102-记录成组)与[可选导览](B-整理关联与查找.md#r103-可选专题页)统一为“记录组＋可选导览”，收录内容只维护一份，两者均安排在后续。导览可在基础成组能力之后增加，具体页面与展示方式随设计确定。

空间能力继续使用同一批地点与原始记录。地点列表与基础小册进入首版，地点星图与真实地图后续安排；地图数据源、工具、地图包及实际离线范围需要在选型后验证。路过提醒暂缓。

时间表达进入首版，章节安排在后续；回看、对照与变化沿用已有后续建议，具体批次分别确定。生活切片、心情天气、安慰小事与声音标本的既有合并结论保持在 D 类正文。

## 主题能力的后续安排

地点星图与轻量生活章节已确认安排在后续，下表保留其最小依赖，供对应迭代使用；详细关系见[整体需求审查](整体需求审查.md)。

| 后续能力 | 所需最小前置 | 可分别安排的增强 |
|---|---|---|
| 地点星图 | 地点身份与记录归属、可用坐标、打开基础地点小册，以及无坐标地点的列表入口 | 真实底图、主题筛选与经历连线；已有地点可补正位置，具体位置选取方式后续设计 |
| 轻量生活章节 | 选定记录的收录与移出、单份引用、章节时间背景及已确认的重叠规则 | 完整专题导览、复杂时间层级；不能因复用记录组就默认全部组内增强同版上线 |

一般排期也按子能力检查依赖：基础搜索随已有内容成立，新增标签或对象条件各自扩展；备份不作为基础记录的前置；照片标注、OCR 和转写按所用媒体分别安排。技术方案与范围未定前，不以组号或条目数量推算开发任务和交付日期。

## 首版完成检查

以下检查对应已确认首版范围，尚未执行；具体交互、保留期限及清理规则仍需随设计补充。

- 未登录、飞行模式下能完成第一条记录的保存。
- 只保存一张照片也能成立，不要求填写标题或先分类；相册原文件删除后，Folio 内照片仍可用。
- 文字、照片、基础录音和基础清单能单独使用、自由组合、补充并重新打开；清单事项可标记完成与未完成。
- 某项权限被拒后，其他记录方式仍可使用。
- 中断后可恢复已成功保存的文字、照片、已录好的声音及其他已支持的草稿信息，如实说明保存结果及可重试的失败。
- 新建草稿点“完成”后才进入正式记录流与搜索；修改已有记录时，完成前保留旧内容的展示，完成后统一更新，也可放弃本次修改。
- 补记旧事时事件时间与记录时间分开；模糊时间按已知范围浏览与筛选。
- 同名对象不自动合并，改名后关联仍有效。
- 文字标签、星标和置顶可添加与取消；取消标记不删除记录。
- 搜索能找到已输入的正文、标签、对象名和说明；时间、标签、媒体类型、星标及具体对象等已支持条件可组合缩小范围，不搜索原照片中的文字或原录音中的话语。
- 地点可命名、复用并选填坐标；无坐标地点仍能通过列表进入基础小册，查看关联内容并打开原记录，完成编辑后各处同步更新。
- 删除后可撤销或从回收站恢复；内容及仍有效的标签、对象归属、组内收录和直接关联一起恢复，已不存在的目标不连带重建；排序冲突等具体细节随设计明确。

## 后续能力完成检查

以下检查随对应能力安排，不作为当前基础功能完成的前提，尚未执行：

- 生活章节：重叠章节和少量记录可正常使用；移出不删除原记录。
- 地点星图：地点与列表打开同一小册，无坐标地点仍可找回；主题筛选与连线按对应迭代范围验收。
- 完整备份与恢复：在支持该备份的环境中恢复后，内容、关系和设置完整；恢复失败时原有资料仍可用。
- 单条私密：默认不在主动回看中展示，访问验证与主动选取规则明确。
- 全局体验：字号和动效调整后仍能操作，手势有按钮替代，空白与失败状态有明确说明。
- 后续 AI：结果可回到原始材料核对、修改或移除；关闭增强后基础离线能力仍可用。

其他已保留能力按选入的迭代验收：复制得到独立记录；合并保留原记录和原引用；拆分保留原记录剩余内容；季节范围调整不改变旧记录原时间范围。尚未支持的能力不因列入此处而自动进入当前迭代。
