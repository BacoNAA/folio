# 版本规划与审核事项

本文保存现行能力的分期建议、验收范围和待决定问题。具体内容与确认状态以各能力正文为准；生活场景只用于举例。

## 分期建议

下表用于决定开发顺序，具体批次与日期仍待确定。已明确首版或后置的结论继续有效，其余建议不等于已经确定上线版本。

| 阶段 | 重点 | 范围 |
|---|---|---|
| 首版候选 | 完成记录、保存、补充与找回 | 无账户开始、文字与照片、多媒体组合、草稿、基础线索、标签与重点标记、时间流、搜索筛选、删除恢复；地点列表与小册是否首版另行决定 |
| 首版特色候选 | 在少量内容下体现主题价值 | [地点星图](C-地点与空间.md#r037-地点星图)、[轻量生活章节](D-时间章节与回看.md#r042-轻量生活章节)，也可以先不选特色 |
| 后续建议 | 扩展内容形式、关联及回看 | 视频、文件、链接、已有音频导入、记录直接关联与纠错、真实地图、地点体验、时间分层浏览、同日与季节回看、未来胶囊、照片对照、变化、颜色与随机回看 |
| 上线批次待定 | 按完整用途安排增强 | 清单、照片标注、复制、模板、合并拆分、个人图章、刻度、状态、情境组合、记录成组、可选专题页、地点待办及对象小册 |
| 后续数据保护 | 基础功能完成后安排 | [单条私密](H-隐私与数据保护.md#r078-单条私密记录)、[完整备份](H-隐私与数据保护.md#r079-完整备份)、[从备份恢复](H-隐私与数据保护.md#r080-从备份恢复) |
| 后续体验完善 | 功能开发后统一完善 | 字号与清晰对比、手势的按钮替代、减少动效、完整空白与失败状态 |
| 后续 AI | 可选择的识别与找回增强 | 图片文字识别、录音转文字、自然语言找回及用户控制规则；全部不进入首版 |
| 暂缓 | 当前不安排 | 应用锁、备份提醒、独立文件夹系统、接收其他应用分享、声音记号和路过提醒 |

[照片记录](A-记录与保存.md#r003-照片记录)、[保存反馈](A-记录与保存.md#r007-清楚的保存反馈)、[草稿恢复](A-记录与保存.md#r008-草稿与中断恢复)和[编辑补充](A-记录与保存.md#r009-编辑与补充)已明确首版保留。声音与其他媒体的具体首版范围仍在组合记录能力内确定，首版不做转写。

[模板](A-记录与保存.md#r094-自定义记录模板)和[刻度](B-整理关联与查找.md#r098-自定义感受刻度)、[状态](B-整理关联与查找.md#r099-自定义状态标记)共用同一项信息；[复制](A-记录与保存.md#r093-复制记录)、[合并](A-记录与保存.md#r095-合并零散记录)、[拆分](A-记录与保存.md#r096-拆分记录)的时间、内容及引用处理规则随对应能力细化。

[记录成组](B-整理关联与查找.md#r102-记录成组)与[可选专题页](B-整理关联与查找.md#r103-可选专题页)保留。主题名称和使用场景在这些功能中举例，具体展示方式随设计确定。

空间能力继续使用同一批地点与原始记录。地点星图、真实地图和地点列表各有适用范围；地图数据源、工具、地图包及实际离线范围需要在选型后验证。路过提醒暂缓。

时间表达、章节、回看、对照与变化均沿用已保留方向，具体批次分别确定。生活切片、心情天气、安慰小事与声音标本的既有合并结论保持在 D 类正文。

## 首版完成检查

以下检查尚未执行；是否纳入验收以最终首版范围为准。

- 未登录、飞行模式下能完成第一条记录的保存。
- 只保存一张照片也能成立，不要求填写标题或先分类；相册原文件删除后，Folio 内照片仍可用。
- 文字、照片及选入本版的其他内容形式能组合、补充并重新打开。
- 某项权限被拒后，其他记录方式仍可使用。
- 中断后可恢复已经保存的草稿内容，如实说明保存结果及可重试的失败。
- 补记旧事时事件时间与记录时间分开；选入本版的模糊时间按已知范围浏览与筛选。
- 同名对象不自动合并，改名后关联仍有效。
- 搜索能找到已输入的正文、标签、对象名和说明；未启用识别或转写时不搜索原媒体中的文字或话语。
- 删除后可撤销或从回收站恢复，并按最终规则恢复内容与关联。
- 选择章节时，重叠章节和少量记录可正常使用；移出不删除原记录。
- 选择星图时，地点与列表打开同一小册，无坐标地点仍可找回；主题筛选与连线只在纳入本版时验收。

## 后续能力完成检查

以下检查随对应能力安排，不作为当前基础功能完成的前提，尚未执行：

- 完整备份与恢复：在支持该备份的环境中恢复后，内容、关系和设置完整；恢复失败时原有资料仍可用。
- 单条私密：默认不在主动回看中展示，访问验证与主动选取规则明确。
- 全局体验：字号和动效调整后仍能操作，手势有按钮替代，空白与失败状态有明确说明。
- 后续 AI：结果可回到原始材料核对、修改或移除；关闭增强后基础离线能力仍可用。

- **Q05** 事件时间、记录时间和补记旧事的填写交互怎样设计？

- **Q07** 回收站保留多久，自动清理与彻底删除怎样处理？
