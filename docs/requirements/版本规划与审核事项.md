# 版本规划与审核事项

[返回需求总索引](../Folio-需求与设计文档-v0.1.md)

本文汇总分期建议、首版候选检查项和待决定问题。具体能力、阶段与审核状态以各类 R 条目为准；确认保留不等于确认进入首版。

## 分期建议

以下安排用于确定开发优先顺序，不代表已确定的上线批次或时间承诺。先完成基础功能，后置能力不作为当前基础实现的前提。

首版刻意不做人物和物件大模块、复杂的时间缩放和回信。历年同日这类回顾功能可以利用导入的旧照片，但首版的价值不能建立在“用了很多年之后”。

人物或物件的轻量对象小册，先汇集已关联记录，不要求建立完整档案；其具体上线版本仍待确定。

这张表是审核候选清单，不是一次全部实现的承诺。[R026](B-整理关联与查找.md#r026-引导式找回) 属于探索，不在首版范围。若选 [R037](C-地点与空间.md#r037-地点星图)，需明确首版的星点与地点小册联动范围，主题筛选和连线可后续增加；选 [R042](D-时间章节与回看.md#r042-轻量生活章节) 时才有章节入口及过滤；选 [R068](G-陈列展馆与内容输出.md#r068-照片陈列柜) 时带上其最小加入、移出、排序和列表操作。所选特色按实际范围验收，也可以先不选特色功能；备份后续实现时应覆盖已启用特色的内容与关系。

## 首版完成检查

以下项目尚未测试，待版本范围确定后用于验收。

以下为候选检查清单，是否执行以功能的最终版本范围为准。当前先确认核心能力，保护性措施的详细验收后续细化。

- 未登录、飞行模式下，能完成第一条记录的保存。
- 只拍一张照片、什么字都不写，也能保存。
- 拒绝麦克风权限后，仍然能记文字和使用其他不依赖麦克风的记录方式。
- 录音时切换应用或遇到中断，回来后能恢复已成功保存的草稿和声音片段，未保存部分有明确提示。
- 补记旧事时，事件时间不会自动变成今天；“2016 年夏”能正常保存和过滤。
- 两个同名人物不会被自动合并。
- 搜索能搜到说明文字，界面写明无法搜索录音和照片里的内容。
- 删除后能撤销，也能从回收站恢复。
- 选择章节特色时，同一记录在章节和地点下引用，修改一处，两处都更新；章节可以重叠。
- 选择星图特色时，星点与地点列表打开同一地点小册，无坐标的地点仍可从列表找回；已有个人地点不依赖底图更新。主题筛选或连线仅在选入本版后验收。
- 选择陈列柜特色时，能选封面、排序、点开和移出；移出不删除原记录，文字或录音记录也能展示。
- 可读导出只包含选中的记录。
- 所选特色在少量地点、只有 3 条记录的章节，或空展柜、单件陈列时仍正常、体面；未选择的功能不作为首版验收要求。

## 后续能力完成检查

以下检查随对应能力的后续开发安排，不作为当前基础功能完成的前提，尚未执行：

- 完整备份与恢复：从单份备份恢复到兼容的测试环境后，媒体、已启用功能的关联与排列完整；恢复失败时，原有记录仍可用。
- 单条私密：默认不进入主动回看、陈列和可读导出或分享；用户可主动查看，具体访问验证方式后续确定。
- 全局体验：字体调整与减少动效后仍可完成操作，手势有按钮替代，空白与失败状态有清楚的下一步说明。
- 后续 AI：识别、转写或找回结果能回到原始内容核对；关闭功能后，原始记录与基础离线使用不受影响。具体实现方案确定后再细化检查。
