# 版本规划与审核事项

[返回需求总索引](../Folio-需求与设计文档-v0.1.md)

本文保存现行能力的分期方向和验收范围。具体内容与确认状态以各能力正文为准；生活场景只用于举例。未决范围集中在[待确认问题](待确认问题.md)。

## 迭代安排方式

当前先明确需要实现的功能及使用结果，暂不展开技术实现和具体界面方案。功能范围清楚后，再结合必要性、实现难度与最小前置划分多个开发迭代；每轮交付可以完整使用和验证的能力，逐步增加功能并保持统一设计。

已明确的首版与后置方向继续保留。下表用于整理上线方向，不是已经排好的开发迭代；首版所含能力也可以经过多轮开发逐步完成。具体迭代数量、顺序与每轮范围后续统一安排，不将全部已保留需求集中到一个版本实现。

## 分期建议

下表用于决定开发顺序，具体批次与日期仍待确定。已明确首版或后置的结论继续有效，其余建议不等于已经确定上线版本。

| 阶段 | 重点 | 范围 |
|---|---|---|
| 首版候选 | 完成记录、保存、补充与找回 | 无账户开始、文字与照片、多媒体组合、草稿、基础线索、标签与重点标记、时间流、搜索筛选、删除恢复；地点列表与小册是否首版另行决定 |
| 首版特色候选 | 在少量内容下体现主题价值 | [地点星图](C-地点与空间.md#r037-地点星图)、[轻量生活章节](D-时间章节与回看.md#r042-轻量生活章节)，也可以先不选特色 |
| 后续建议 | 扩展内容形式、关联及回看 | 视频、文件、链接、已有音频导入、记录直接关联与纠错、真实地图、地点体验、时间分层浏览、同日与季节回看、未来胶囊、照片对照、变化、颜色与随机回看 |
| 上线批次待定 | 按完整用途安排增强 | 清单、照片标注、复制、模板、合并拆分、个人图章、刻度、状态、情境组合、记录成组、可选专题页、地点待办及对象小册 |
| 后续数据保护 | 基础功能完成后安排 | [单条私密](H-隐私与数据保护.md#r078-单条私密记录)、[完整备份](H-隐私与数据保护.md#r079-完整备份)、[从备份恢复](H-隐私与数据保护.md#r080-从备份恢复) |
| 后续体验完善 | 功能开发后统一完善 | 字号与清晰对比、手势的按钮替代、减少动效、完整空白与失败状态 |
| 后续 AI | 可选择的识别与找回增强 | 图片文字识别、录音转文字、自然语言找回及用户控制规则；全部不进入首版 |
| 暂缓 | 当前不安排 | 应用锁、备份提醒、独立文件夹系统、接收其他应用分享、声音记号和路过提醒 |

[照片记录](A-记录与保存.md#r003-照片记录)、[基础声音](A-记录与保存.md#r005-组合记录)、[保存反馈](A-记录与保存.md#r007-清楚的保存反馈)、[草稿恢复](A-记录与保存.md#r008-草稿与中断恢复)和[编辑补充](A-记录与保存.md#r009-编辑与补充)已明确首版保留。基础声音包含应用内录制、停止、试听与播放、单段删除和继续添加；后台长录音与剪辑后续另行安排，首版不做转写。已有音频导入保持独立分期。

新建记录编辑中自动保存草稿，点“完成”后才进入正式记录流与搜索。草稿覆盖已支持的文字、照片、已录好并成功保存的声音，以及清单、地点和标签等已填写内容。修改已有记录时，完成前保留上一次完成的内容供浏览和找回，未完成修改可继续或放弃，具体规则见 R008、R009。

[模板](A-记录与保存.md#r094-自定义记录模板)和[刻度](B-整理关联与查找.md#r098-自定义感受刻度)、[状态](B-整理关联与查找.md#r099-自定义状态标记)共用同一项信息；复制、合并、拆分各自的内容结果、时间和引用规则已明确，见[共同规则](A-记录与保存.md#复制合并与拆分的共同规则)，具体设计细节随对应迭代细化。

[记录成组](B-整理关联与查找.md#r102-记录成组)与[可选导览](B-整理关联与查找.md#r103-可选专题页)统一为“记录组＋可选导览”，收录内容只维护一份。导览可在基础成组能力之后增加，具体页面与展示方式随设计确定。

空间能力继续使用同一批地点与原始记录。地点星图、真实地图和地点列表各有适用范围；地图数据源、工具、地图包及实际离线范围需要在选型后验证。路过提醒暂缓。

时间表达、章节、回看、对照与变化均沿用已保留方向，具体批次分别确定。生活切片、心情天气、安慰小事与声音标本的既有合并结论保持在 D 类正文。

## 选择特色时一起确认的范围

下表说明当前方案已经使用的最小依赖，不表示任何候选已进入首版；详细关系见[整体需求审查](整体需求审查.md)。

| 候选 | 一起确认的最小范围 | 可分别安排的增强 |
|---|---|---|
| 地点星图 | 地点身份与记录归属、可用坐标、打开基础地点小册，以及无坐标地点的列表入口 | 真实底图、主题筛选与经历连线；已有地点可补正位置，具体位置选取方式后续设计 |
| 轻量生活章节 | 选定记录的收录与移出、单份引用、章节时间背景及已确认的重叠规则 | 完整专题导览、复杂时间层级；不能因复用记录组就默认全部组内增强同版上线 |
| 先不选择特色 | 完成选定内容形式的创建、编辑、保存、重新打开与基础找回 | 不因此否定已保留的主题方向，具体批次继续分别安排 |

一般排期也按子能力检查依赖：基础搜索随已有内容成立，新增标签或对象条件各自扩展；备份不作为基础记录的前置；照片标注、OCR 和转写按所用媒体分别安排。具体平台与范围未定前，不以组号或条目数量推算开发任务和交付日期。

## 首版完成检查

以下检查尚未执行；是否纳入验收以最终首版范围为准。

- 未登录、飞行模式下能完成第一条记录的保存。
- 只保存一张照片也能成立，不要求填写标题或先分类；相册原文件删除后，Folio 内照片仍可用。
- 文字、照片及选入本版的其他内容形式能组合、补充并重新打开。
- 某项权限被拒后，其他记录方式仍可使用。
- 中断后可恢复已成功保存的文字、照片、已录好的声音及其他已支持的草稿信息，如实说明保存结果及可重试的失败。
- 新建草稿点“完成”后才进入正式记录流与搜索；修改已有记录时，完成前保留旧内容的展示，完成后统一更新，也可放弃本次修改。
- 补记旧事时事件时间与记录时间分开；选入本版的模糊时间按已知范围浏览与筛选。
- 同名对象不自动合并，改名后关联仍有效。
- 搜索能找到已输入的正文、标签、对象名和说明；具体对象及其他已选入本轮的条件可组合缩小范围，未启用识别或转写时不搜索原媒体中的文字或话语。
- 删除后可撤销或从回收站恢复；内容及仍有效的标签、对象归属、组内收录和直接关联一起恢复，已不存在的目标不连带重建；排序冲突等具体细节随设计明确。
- 选择章节时，重叠章节和少量记录可正常使用；移出不删除原记录。
- 选择星图时，地点与列表打开同一小册，无坐标地点仍可找回；主题筛选与连线只在纳入本版时验收。

## 后续能力完成检查

以下检查随对应能力安排，不作为当前基础功能完成的前提，尚未执行：

- 完整备份与恢复：在支持该备份的环境中恢复后，内容、关系和设置完整；恢复失败时原有资料仍可用。
- 单条私密：默认不在主动回看中展示，访问验证与主动选取规则明确。
- 全局体验：字号和动效调整后仍能操作，手势有按钮替代，空白与失败状态有明确说明。
- 后续 AI：结果可回到原始材料核对、修改或移除；关闭增强后基础离线能力仍可用。

其他已保留能力按选入的迭代验收：复制得到独立记录；合并保留原记录和原引用；拆分保留原记录剩余内容；季节范围调整不改变旧记录原时间范围。尚未支持的能力不因列入此处而自动进入当前迭代。
