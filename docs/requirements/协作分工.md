# 工作拆分

[返回需求总索引](../Folio-需求与设计文档-v0.1.md)

本页将需求细化与后续开发拆成两个工作包，说明各自范围和依赖关系。工作拆分不改变各 R 条目的审核状态或上线阶段。

## 工作包一：核心能力与时空体验

- A 类中的记录编辑、组合、模板、保存、草稿、合并与拆分等核心能力，不含工作包二列出的 8 项媒体与快捷记录能力。
- B 类整理、标签、对象线索、关联、搜索、记录成组与专题页。
- C 类地点与空间、D 类时间与回看。
- H 类数据保护、I 类全局交互、J 类后续能力，继续按各自阶段审核。
- 整体产品方向、统一设计、目标平台、首版范围与分期。

## 工作包二：媒体、人物与收藏展示

| 范围 | 需求入口 | 编号数 |
|---|---|---:|
| 媒体与快捷记录 | [R003 照片](A-记录与保存.md#r003-照片记录)、[R004 录音](A-记录与保存.md#r004-原始录音)、[R029 视频](A-记录与保存.md#r029-视频)、[R030 文件附件](A-记录与保存.md#r030-文件附件)、[R031 链接](A-记录与保存.md#r031-链接)、[R088 快捷入口](A-记录与保存.md#r088-快捷记录入口)、[R090 音频导入](A-记录与保存.md#r090-导入已有录音)、[R092 照片标注](A-记录与保存.md#r092-照片绘制与标注) | 8 |
| 人物与共同回忆 | [E 类](E-人物与共同回忆.md)：人物小册、礼物往来、双人回忆交换 | 3 |
| 物件管理与私人收藏 | [F 类](F-物件管理与私人收藏.md)：位置、当前状态、使用资料、图鉴与履历等 | 8 |
| 陈列、展馆与内容输出 | [G 类](G-陈列展馆与内容输出.md)：展签、特展、陈列、小志、导出与分享等 | 12 |
| **合计** | 需求细化与开发范围，分批审核和实现 | **31** |

两个工作包均包含使用场景梳理、需求取舍、方案设计、开发和验收。待审核条目先细化方案；已保留条目继续确定范围和分期。立体展厅、真实 3D、回忆交换等探索或后续能力不因归入工作包而提前启动。

## 共用能力与依赖关系

工作包一明确记录和媒体的保存方式、对象身份及同名处理、时间表达、引用关系、搜索、自定义刻度与状态等共用规则。各功能使用同一份记录和媒体，不为人物、图鉴或展馆另外复制一套内容。

工作包二的拍照、录音、视频和导入能力接入统一记录与媒体保存机制，草稿与恢复与核心记录流程衔接。人物和物件页面使用 B 类对象线索；导出、交换与陈列遵循共用的引用、内容选择及数据保护规则。尚未审核的规则仍按原状态推进。

各工作包剩余审核数量以[总索引](../Folio-需求与设计文档-v0.1.md#当前审核位置)为准。本页只维护工作范围与依赖关系，不重复保存功能正文或审核状态。
