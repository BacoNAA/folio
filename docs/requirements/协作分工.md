# 工作范围与协作

[返回需求总索引](../Folio-需求与设计文档-v0.1.md)

当前先明确功能范围及使用结果；之后按必要性、难度和前置依赖划分迭代，再安排具体设计与实现。负责人、开发任务和交付日期待平台与迭代范围确定后安排。使用示例不单独分配工作包或验收任务。

能力归属与前置关系以[整体需求审查](整体需求审查.md)为索引。下表是工作范围，不等同于必须串行完成的开发模块；每项正文与阶段仍在所属分类文件维护。

## 当前工作范围

| 范围 | 内容 |
|---|---|
| 记录与媒体 | 文字、照片、基础声音与组合记录、视频、附件、链接、音频导入、清单、照片标注、编辑与保存、草稿、模板及记录重组 |
| 整理与找回 | 标签与标记、对象线索、关联与纠错、记录组及其可选导览、浏览、搜索和筛选 |
| 地点与时间 | 地点资料、可选坐标、地点浏览、个人体验与待办、星图与后续地图、时间表达、章节和回看 |
| 数据与共同体验 | 删除恢复、后续私密及备份、全局交互、后续识别与智能找回 |
| 产品与分期 | 目标平台、首版范围、原则、统一设计及版本安排 |

## 协作要求

- 按完整可验收结果安排交付。记录流程应包含输入、编辑、保存、重新打开与基本反馈，媒体输入与草稿恢复需要一起验证。
- 各范围使用同一份记录、媒体和对象身份；共用时间、引用、搜索及状态语义，避免重复维护内容。
- 地点与时间体验复用记录与整理能力，具体子能力可分别分期。
- 备份、私密及 AI 保持已确认的后置安排；暂缓项按总索引执行。
- 同一能力可拆开发任务，但不因此新增独立产品需求。具体人员分配与工作包数量随实施安排确定。
- 合作前明确操作前后保留的内容、共用信息和关系结果。创建关联与纠错等完整操作一起定义；共用规则不要求所有使用它的增强一起上线。
- 有歧义的部分查[待确认问题](待确认问题.md)，只暂停依赖该答案的细化；记录、对象、标记和组织的已有明确能力仍可继续整理。不得以实现方便自行选定未确认行为。
- 验收说明分别写明方向、范围和阶段，不能把“已保留”当作设计完成；当前均尚未开发。

功能状态和待决定问题见[需求总索引](../Folio-需求与设计文档-v0.1.md)与[版本规划](版本规划与审核事项.md)。
