2026-11-08 更新。本页维护待定事项和已确认结论的索引。Q 编号用于讨论，具体功能规则见对应的需求文档。

## 阅读与处理方式

- 功能及其使用结果确认后，后续按必要性、难度与前置关系划分开发迭代，具体界面和实现方案随后确定；技术主线、设备兼容与交付及首版迭代安排已确认，下一步先推进整体原型与关键数据设计。
- 已确认的范围写入正文；有歧义的部分继续保留问题，只暂停依赖该答案的细化。
- 原有首版与后置结论继续有效；保留一项能力不意味着全部增强必须在同一开发迭代完成。
- Q01—Q08 延续原版本问题，Q09—Q22 用于结构评审中的范围澄清。已结清的编号保留在下方索引，不重复审核。
- 产品原则 P01—P09 均已确认，正文见[产品方向与原则](产品方向与原则.md)；原则确认不提前后置能力，具体视觉与界面方案仍待设计。

## 当前审核进度

首版主流程与页面组织已确认，连续编辑、记录浏览与组合筛选，以及地点选择、共享资料保存和带草稿的删除恢复交互也已确认，见[主流程汇总](版本规划与审核事项.md#首版主流程与页面组织已确认)。时间、对象、标签和标记的规则见[已确认的保存关系](../design/首版原型与关键数据设计.md#已确认的保存关系)。人物与物件同时筛选时须匹配两者，具体选择界面与视觉样式另行评审。

核心功能边界、P01—P09 九条产品原则、五方面首版内容、五项技术主线及设备兼容与交付安排均已确认，并写入对应正文。首个目标平台为安卓（Android）；首版包含记录与维护、基础整理、浏览查找、基础地点浏览和删除恢复，见[首版范围](版本规划与审核事项.md#首版范围已确认)。[技术主线](版本规划与审核事项.md#技术主线已确认)采用成熟组件组合、Kotlin＋Jetpack Compose、Room／SQLite、既有媒体组件及单应用模块分层组织。[设备兼容与交付](版本规划与审核事项.md#设备兼容与交付已确认)以 Android 10 及以上手机为目标，基础功能不强制依赖 Google Play 服务，每轮可用版本提供已签名 APK。[首版迭代安排](版本规划与审核事项.md#首版迭代安排已确认)已确认：先完成整体原型与关键数据设计，再按文字与照片、录音与清单、整理与地点、完整时间与组合查找四轮推进。地图供应商、具体工作量与交付日期仍待落实；具体依赖版本随实施验证。

探店记录、补记旧事、物件与收藏展示的使用流程也已核对确认，详见[使用场景](使用场景.md)。本次确认说明已有能力如何配合，以下规划、界面与后续增强问题仍保持待定。

Q04、Q08 及 Q18 剩余的后续 AI 结果细则仍在下一节；Q01、Q02、Q03、Q05、Q06、Q07 的结论已移至下方已确认索引，P01—P09 的九条已确认原则在产品方向文档维护。首版地点通过搜索面板选择，坐标由用户主动获取当前位置并确认；地图选点随后续地图提供。默认季节月份、跨年归属与模糊时间结果呈现已经确认，见 Q22。拆空原记录、恢复时的组内排序冲突等未讨论细节随对应设计继续明确。图谱、自由画布和自动条件合集等候选仍未纳入已确认开发范围。

## 已确认的功能边界

以下只记录结论摘要与正文入口；具体操作规则以正文为准。

| 编号 | 已确认结论与正文 |
|---|---|
| **Q09** | 基础声音范围保留，草稿覆盖已支持的文字、照片、已录好并成功保存的声音及已填写信息；见 [R005](A-记录与保存.md#r005-组合记录)、[R008](A-记录与保存.md#r008-草稿与中断恢复)。 |
| **Q10** | 多条新建草稿可独立续写，临时切换应用后续写当前草稿。新建完成后回「随手记」，已有记录完成后回详情。未完成的修改可继续或放弃。见 [R007](A-记录与保存.md#r007-清楚的保存反馈)、[R008](A-记录与保存.md#r008-草稿与中断恢复)、[R009](A-记录与保存.md#r009-编辑与补充)。 |
| **Q11** | 对象与记录的当前状态独立设置，可按需留下状态变化历史；地点整体印象与当次体验分别保留；见 [R099](B-整理关联与查找.md#r099-自定义状态标记)、[R034](C-地点与空间.md#r034-口味刻度)。 |
| **Q12** | 模板可复用已有项目，同名项目由用户决定共用或分开；改模板不改旧记录。同一标签改名或换图案同步显示，刻度含义改变保留旧取值；见 [R094](A-记录与保存.md#r094-自定义记录模板)、[共用项目与变更规则](B-整理关联与查找.md#共用项目与变更规则)。 |
| **Q13** | 组合按记录当前条件匹配；改组合搭配影响之后套用和当前组合查找，不改写旧记录；见 [R101](B-整理关联与查找.md#r101-情境组合标签)。 |
| **Q14** | 统一为“记录组＋可选导览”，收录内容维护一份；页面划分后续设计；见 [R102](B-整理关联与查找.md#r102-记录成组)、[R103](B-整理关联与查找.md#r103-可选专题页)。 |
| **Q15** | 地点选择用名称、独立选填的城市／地址／备注及当前选中状态区分同名对象。换地点与新建地点草稿随记录完成生效；小册中的共享地点资料独立保存并更新所有引用，保留地点身份。坐标由用户主动获取并确认，已有位置可补正，地图选点后置。见 [R013](C-地点与空间.md#r013-手动填写地点)、[R014](C-地点与空间.md#r014-可选附加定位坐标)。 |
| **Q16** | 复制形成独立记录；合并生成新记录并保留原记录；拆分移出所选部分，原记录保留剩余。可沿用或调整时间与线索，新记录有自己的记录时间，原有组内位置和直接关联不自动转移；拆空原记录等细节待设计，见 [A6 复用与重组](A-记录与保存.md#a6-复用与重组)。 |
| **Q17** | 恢复原正式内容、未完成草稿及仍有效的标签、对象归属、组内收录和直接关联，不自动发布草稿；已不存在的目标不连带重建。组内排序冲突等未讨论细节继续待定，见 [H1 删除与恢复](H-隐私与数据保护.md#h1-删除与恢复)。 |
| **Q19** | 三个入口分别搜索全部正式记录、地点资料或当前地点的记录。普通筛选中不同类别同时满足，同类多选默认任一。各条件可见并可单独移除，清除筛选保留关键词；无结果时由用户主动放宽范围，返回时保留条件与位置。见 [R024](B-整理关联与查找.md#r024-文字搜索)、[R025](B-整理关联与查找.md#r025-时间与类型过滤)。 |
| **Q20** | 关联具体清单事项与实际体验记录，支持补写或关联已有记录，勾选完成独立使用；见 [R035](C-地点与空间.md#r035-下次想试)。 |
| **Q21** | 收藏展示以记录组和导览为内容基础，可组织物件照片、来历与声音，按主题和顺序欣赏并打开原记录；3D 保留为后续呈现探索，独立建模等额外能力另议；见 [R102](B-整理关联与查找.md#r102-记录成组)。 |
| **Q22** | 按年区分具体日期与大概时间，另列跨年经历与时间未定；时间结果区分明确与可能并分别计数。默认春 3—5 月、夏 6—8 月、秋 9—11 月、冬当年 12 月至次年 2 月；命名季节按填写年归组，按实际范围筛选，改季节设置不改旧记录。最近经历仍按可确定事件时间表达。见 [R012](D-时间章节与回看.md#r012-模糊时间)、[R023](B-整理关联与查找.md#r023-时间流)、[R032](C-地点与空间.md#r032-地点列表)。 |
