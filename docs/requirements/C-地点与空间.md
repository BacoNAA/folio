# C｜地点与空间

[返回需求总索引](../Folio-需求与设计文档-v0.1.md)

**本类审核什么**：地点信息怎样与记录关联，以及怎样通过地点小册、星图或地图找回内容。

本类按地点信息、地点浏览、空间呈现、地点应用组织。地点名称与记录关联是共用基础；列表和小册不依赖坐标或真实底图。各条目的去留和阶段保持独立，归在同一部分不要求同时上线。完整关系见[整体需求审查](整体需求审查.md)。

## 能力关系

| 能力 | 所需基础或复用关系 | 范围边界 |
|---|---|---|
| 地点信息 | 对象身份规则与记录归属 | 名称可以单独使用，坐标可选且可后补或更正，保留同一地点与原关联记录；不要求先有完整地点档案 |
| 地点列表与小册 | 地点及其关联记录、原记录的读取与编辑、共同时间规则 | 两者组成按地点查看的流程；最近经历按事件时间判断并保留不确定性，无需先实现星图或地图 |
| 地点星图 | 已有可用坐标、地点信息与基础地点小册 | 选择星图时一起明确这些最小前置；主题筛选和经历连线仍可后续完善 |
| 真实地图 | 地点与坐标、实际支持的底图资源 | 与星图共用内容和视觉规则，二者不互为必须前置 |
| 地点感受与清单 | 复用已有刻度、状态、清单与地点小册 | 整体印象与单次感受分别保留；实际体验关联到具体清单事项，不新增一套评分或清单系统 |

## C1 地点信息

地点信息属于记录线索，与具体空间视图分别确定范围。

### R013 手动填写地点

地点名可以自由新建，也可以从以前用过的地点里选。同一家店写过一次，下次输入时会出现在提示里；城市、地址和备注都可以选填，只有名字也能保存。

同名地点可以分别保留，通过选填的城市、地址或备注帮助区分，不会只因名字相同就合并。以后修改地点名或补充资料，原来关联的记录仍然保留在这个地点下。

地点与人物、物件共用 [R016](B-整理关联与查找.md#r016-同名不自动合并) 的对象身份规则；地点名称和坐标是不同信息，不因补充坐标另建一份地点。

【阶段：首版建议】【审核：保留；自由新建与复用、选填资料、同名区分及关联保留已确认】

### R014 可选附加定位坐标

坐标是可选的地点线索，可以在现场记录时尝试获取当前位置，成功后由用户确认是否附上，供地点星图或以后的真实地图使用。不添加坐标，也能保存地点名和记录，并通过地点列表找回。

补记旧事时，手机当前所在的位置不代表当时的事件地点，不能自动填入。坐标也不会自动变成“某某餐厅”，不作为可靠的到达判断。

已有地点可以补充或更正位置，仍保留同一个地点及其原来关联的记录，不因补充位置另建地点。没有位置时，仍能通过地点名称在列表中找回。

具体如何选择位置后续设计，见[待确认问题 Q15](待确认问题.md)；尚未确定地图选点、联网搜索或其他坐标来源。

【阶段：首版建议】【审核：保留；坐标可选、已有地点可补充或更正位置并保留关联、补记地点不取当前位置及坐标与店名分开已确认】

## C2 地点浏览与小册

列表帮助找到地点，小册集中查看该地点的记录。已选择上线的空间视图接入同一小册，视图之间不另存一套内容。

### R032 地点列表

空间总览是按地点找回的统一入口，可以用列表或卡片查看自己的地点，也可以切换到地点星图；以后的真实地图沿用同一批地点与内容，不需要重新整理。

可以按地点名称、已填写的城市或地址查找。每个地点可显示记录条数，记录条数不当作到访次数。点开地点进入地点小册，再从小册打开原记录。没有坐标或底图时，列表和卡片仍然可用。

最近经历依据事件时间判断，沿用[时间浏览与匹配共同规则](D-时间章节与回看.md#时间浏览与匹配共同规则)：能够确定先后时显示最近经历的时间，只有时间范围时显示该范围；无法判断哪条最新时保留这种不确定性，不强选一条作为最近经历，仍能查看全部关联记录。时间未定的内容保留原说法或显示“时间未定”，补写时间不替代事件时间。具体呈现方式后续设计。

【阶段：首版建议】【审核：保留；空间总览入口、多种视图共用内容、记录数与到访数分开及最近经历保留时间不确定性已确认】

### R033 地点页

地点页以“地点小册”的形式，集中查看与这个地点关联的记录，比如每次去老王家吃了什么、和谁去的。可以按时间浏览、筛选，并打开其中的原记录；时间不明确的内容沿用基础时间规则，不补造日期。

可以在小册里补一条新记录，也可以把已有记录关联过来。列表、卡片、星图和以后的真实地图都进入同一本地点小册；小册引用原记录。正式记录修改后，点击“完成”才同步更新小册等相关展示，沿用 [R009](A-记录与保存.md#r009-编辑与补充) 的生效规则。只有一条记录也能使用，不要求先填写完整的地点档案。

【阶段：首版建议】【审核：保留；地点小册、时间浏览与筛选、新增及关联已有记录已确认】

## C3 空间呈现与后续提醒

星图和真实地图是并列的呈现能力；共用画风不构成先后上线要求。路过提醒有独立的定位与提醒行为，保持暂缓，不因地图能力保留而启动。

### R036 地图底图

后续保留在真实地图上查看个人地点的能力。个人地点、记录和坐标与地图底图分开保存；底图未下载、过期或暂时不可用，都不阻止记录、编辑和按地点找回。

离线地图以用户主动选择区域下载和更新为设计方向，显示区域的下载时间，不要求频繁更新才能继续使用。下载与更新需要联网；已完整下载且受支持的区域可供离线查看，未下载或不支持的区域回到地点列表。

矢量底图自定义画风是候选方案，数据源、渲染器、地图包和实际离线支持范围均须在选型后验证，目前没有确定具体技术。真实地图沿用地点星图的个人标记、卡片、字体和配色，降低底图的视觉权重，同时保留地理位置的准确表达。

【阶段：后续建议】【审核：保留；个人数据与底图分开、主动下载更新及统一画风已确认；技术选型与离线范围待验证】

### R037 地点星图

不依赖真实底图，按已有坐标的相对地理位置把地点呈现为星点；地点跨度较大时，可以按城市聚合。星点可以配上代表照片或名称，点开后进入同一本地点小册。没有坐标的地点仍在列表或卡片中查看，单个地点、少量记录也能独立呈现。

可以从用户选定的记录组中挑出地点，按用户确认的顺序连接，表示“我经历过怎样的一段路”。连线表达经历顺序，不代表导航路线；主题筛选和连线能力可在后续版本完善。只有存在明确的多次到访记录时才表现到访频率，不根据照片数、备注数或普通记录条数猜测去过多少次。

【阶段：首版空间特色候选，尚未确认进入首版】【审核：保留；相对地理呈现、地点小册入口及少量内容可用已确认；主题筛选与经历连线可后续完善】

### R038 路过提醒

路过某个记过的地点时，轻轻提醒一句“你在这里记过一道菜”。默认关闭。由于依赖系统定位，提醒可能漏掉或延迟，文档和界面都不承诺准确。

【阶段：暂缓，待可靠性验证】【审核：暂缓】

## C4 地点感受与清单应用

以下条目描述通用标记与清单在地点中的应用，保留已有能力和阶段，分别说明地点整体印象、单次感受和具体事项的实际体验。

### R034 口味刻度

可以分别记录对一个地点的整体印象和某次体验的个人感受，不限于菜品。例如咖啡馆的整体印象是“适合独处、愿意再来”，某次体验仍可以记为“今天太吵”；也可以给某次面馆体验记“辣度 3/5”，给一次公园散步记“很放松”。

地点整体印象由用户主动维护，各次体验独立保留在当次记录中，彼此不覆盖。例如第一次觉得很好、第二次觉得偏咸，两次体验都留下，也不自动改写地点的整体印象。

辣度、喜爱程度、松弛感等程度信息复用 [R098 自定义感受刻度](B-整理关联与查找.md#r098-自定义感受刻度)；地点和单条记录都可以独立设置当前状态，更新及可选变化历史沿用 [R099 自定义状态标记](B-整理关联与查找.md#r099-自定义状态标记)，不改写历史经历与当次感受。不另建一套地点评分，也不要求每次体验都打分。

【阶段：后续建议】【审核：保留；扩展到地点个人体验，并复用感受刻度与状态标记已确认】

### R035 下次想试

在地点小册里放一份与地点关联的清单，记下“下次来想做的事”，例如想点的豆花鱼、想坐的靠窗位置，或下次到公园想走的小路。再次打开小册时，可以查看和勾选这些事项。

可以将已有的实际体验记录关联到具体清单事项，也可以补一条新记录再关联；查看该事项时能找到实际结果。事项勾选与体验关联独立，不强制每次勾选完成都写记录。本条不包含路过提醒。

这里关联到具体事项，不以整条清单记录与体验记录之间的 [R017](B-整理关联与查找.md#r017-手动关联记录) 关联代替。体验内容沿用 [R018](B-整理关联与查找.md#r018-引用而不是复制) 的单份引用规则，不另外复制记录。

【阶段：待定】【审核：保留；地点关联清单、完成状态及关联实际记录已确认】
