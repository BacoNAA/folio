# Folio 整体需求审查

更新日期：2026-10-29。范围：当前有效需求及产品原则、版本问题和协作安排。

[返回需求总索引](../Folio-需求与设计文档-v0.1.md)

## 当前结论

独立功能条目的去留已无待审核或部分确认事项。后续围绕已确认能力细化范围、关系、分期与设计。生活主题、表现形式及普通使用方式只在已有功能中举例。

“随手留下生活细节，需要时找回”的基础目标清楚。空间、时间和重温的兴趣继续保留；具体表现方式随设计探索。主题名称本身不新增功能或开发任务。

本报告不自动改变既有能力的首版、后置或暂缓安排。新的目录组织、原则与实现细节仍按用户确认推进。

## 审查标准

| 维度 | 判断方式 |
|---|---|
| 合理性 | 是否解决具体生活问题或服务已明确兴趣；已有记录、线索、标签或记录组能否满足 |
| 独立性 | 是否有独特用户目标、操作结果和完成标准；输入、页面或主题不同不足以单独成立新需求 |
| 粒度 | 完整能力下维护子操作、规则和示例；分期与具体设计分别决定 |
| 关系 | 区分组成、复用、前置依赖、共同约束、重叠与不同结果 |
| 确认边界 | 方向已保留不等于所有扩展同版上线；设计例子不新增范围承诺 |

本轮依据需求原文与使用场景分析，未进行用户实验或平台性能验证。探索的价值和兼容范围仍需在对应阶段验证。

## 已确认能力中的关系问题

| 问题 | 关系与建议 |
|---|---|
| 记录流程被拆散 | 输入、编辑、保存、草稿、重新打开和反馈应作为完整结果交付，具体媒体分别分期 |
| 模板与标记共用信息 | 模板复用结构，刻度与状态定义信息，组合便于一起套用；同一项内容只填一次，历史感受与当前状态分别表达 |
| 对象身份与记录归属 | 人物、地点或物件可以关联多次经历；改名、补资料与日常纠错不能丢失原记录关系 |
| 内容变换与引用 | 复制产生独立内容，成组保持记录独立，合并和拆分改变内容组织；时间、媒体及原有引用结果应统一定义 |
| 时间解释贯穿多处 | 双时间与模糊精度应同时用于浏览、筛选和回看，不能各自猜测日期 |
| 地点多视图共用资料 | 列表、星图和真实地图使用同一批地点，无坐标或底图时仍有可用入口 |
| 删除恢复的完整性 | 撤销和回收站互补，需明确媒体、对象归属与组内关系的恢复效果 |
| 原始材料与后续编辑 | 保留原图、照片标注、识别和转写应明确各自作用范围，原材料可继续核对 |
| 全局体验的阶段 | 保存结果真实可知和草稿可恢复已有明确要求；完整统一体验的后置不取消这些基础要求 |
| 后续增强的价值 | 引导找回、主色浏览和自然语言入口应与现有搜索筛选比较收益，保留方向与实际优先级分别确认 |

## 待细化的范围与验收

| 能力 | 仍需明确的边界 |
|---|---|
| 内容输入与编辑 | 选定媒体的数量、格式、大小或时长；标注类型；原材料与编辑结果的关系 |
| 保存与恢复 | 已保存草稿、正式记录和未成功保存内容的界线；权限或空间异常后的可用操作 |
| 记录变换 | 复制时的时间与标记；合并拆分后内容顺序、原记录去留和关联处理 |
| 模板、刻度与状态 | 字段类型及共用方式，状态的作用对象和历史含义 |
| 记录组与专题页 | 组内说明与可选导览的边界，具体展示、编辑方式和上线批次 |
| 时间与找回 | 首版支持的时间精度，模糊范围的浏览筛选，回看与未来日期的提示方式 |
| 空间能力 | 星图最小范围，后续地图数据、工具、地图包及实际离线支持 |
| 删除、私密与备份 | 清理与恢复规则，私密访问及主动选取方式，备份保护和支持的恢复环境 |
| 全局体验 | 字号与动效范围、操作替代、状态说明，以及平台明确后的性能目标 |
| 后续 AI | 本机或云端处理、材料范围、结果与原内容的关系、检索衔接和具体版本 |

这些是现有能力的范围或完成标准，随对应阶段设计，不再扩成一批并列需求。

## 原则与版本问题

已明确的 K01—K13 继续作为方向依据。P01—P09 仍是待审核原则，具体表述见[产品方向与原则](产品方向与原则.md)。其中保存不以整理为前提等内容与已确认能力重合，应统一维护。

Q01—Q08 继续见[版本规划](版本规划与审核事项.md)：首版特色、目标平台、首页、付费方式、时间填写交互、地点小册首版安排、回收站规则和私密访问与备份保护。

备份、单条私密与 AI 保持后置；暂缓项按总索引执行。多层嵌套、自动条件合集、关系图谱、自由画布及批量对象处理仍是候选，具体取舍随相关能力另行讨论。

## 协作与后续确认

按完整用户任务细化设计与交付，输入、保存和重新打开共同验收；各范围复用记录、对象身份、时间与引用规则。具体负责人和开发包在平台、版本明确后确定，见[工作范围与协作](协作分工.md)。

后续每轮五组，优先讨论：

1. 目标平台、首版范围及特色。
2. 基础线索与时间表达的首版范围。
3. 模板、标记及组织能力的共同信息。
4. 复制、合并、拆分与恢复的结果规则。
5. 产品原则、统一体验和后续能力的阶段安排。
