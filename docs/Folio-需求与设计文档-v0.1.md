# Folio 需求与设计文档 v0.1 · 总索引

版本日期：2026-10-20。最近审核：2026-10-29。当前阶段：需求评审。

Folio 希望让生活中的细节随手记下、需要时找回。首版优先离线体验，不含 AI；当前先确定能做什么，再细化界面与实现。

本文只维护分类入口、审核进度和阅读顺序。103 个需求编号分在 A—J 十份文档中；各类再分成两到三项相近能力的小组，共 43 组。其中 4 项已并入已有能力，保留编号与承接链接，不再作为独立功能。分类用于审核，不代表应用导航或上线版本。

## 当前审核位置

工作包一“核心能力与时空体验”已完成本轮功能去留审核。基础文字、无账户开始使用、有内容即可保存、复制记录、标签、删除撤销与回收站均已确认保留。独立文件夹系统暂缓，采用标签、记录组与可选专题页组织内容。

按[工作拆分](requirements/协作分工.md)，工作包一剩余 0 项，工作包二“媒体、人物与收藏展示”剩余 26 项，合计 26 项待审核或部分确认：A 类照片、原始录音、快捷入口 3 项，以及 E 类 3 项、F 类 8 项、G 类 12 项。工作划分不改变审核状态；暂缓及已合并项不重复计入待审数量。

后续按工作包二继续审核，同时可集中确定基础版范围和开发顺序。本轮结束只表示功能去留已明确，已保留功能的细节、上线批次，以及产品原则、平台和首版特色等事项仍需另行确定。

## 怎样审核与维护

- 每次按小组讨论两到三项相近能力，先确认用途、价值与版本。当前不展开按钮、入口或布局；保护性措施后续细化。
- 可以按小组或 R 编号提出“保留、修改、暂缓、合并、删除”；P 编号用于产品原则，Q 编号用于待决定问题。
- 一组反馈明确后统一更新。没有明确确认的内容仍为提案；“首版建议”只是候选，功能保留与上线版本分别登记。
- 每项 R 需求只在所属分类文件保留一份正文；正文中的阶段和审核状态为准。其他文档通过链接引用，版本与场景只是汇总或例子。
- 总数、状态统计与当前审核位置只在本索引维护。功能增删或状态变化时同步更新；分期或原则变化时同步相关配套文档。
- 新功能接续 R 编号，调整分类不改编号；删除或合并的编号不重新使用，合并条目注明承接能力。每类保留小组目录和返回总索引的链接。
- 导航使用 Markdown 文件链接与标题链接，不使用 HTML 锚点。文件名或标题变更时同步检查引用。
