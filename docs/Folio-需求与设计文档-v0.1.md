# Folio 需求与设计文档 v0.1 · 总索引

版本日期：2026-10-20。最近更新：2026-10-29。当前阶段：需求评审与设计。

Folio 希望让生活中的细节随手记下、需要时找回。首版优先离线体验，不含 AI；当前先确定能力范围，再细化界面与实现。

本文维护能力入口、审核统计和阅读顺序。现存编号用于定位正文，分类和编号数量不代表应用导航、独立功能数或开发进度。

## 当前审核位置

已完成一轮[整体需求审查](requirements/整体需求审查.md)。按照用户决定，场景、表现形式及已有能力的使用方式不再单独列为需求，也不保留它们的编号、承接关系或历史待办。

当前独立条目的功能去留已无待审核或部分确认事项。后续主要确认：

- 产品原则及整体组织方式。
- 已保留能力的具体范围、相互关系与上线批次。
- 目标平台、首版特色和首页组织。
- 记录变换、删除恢复、私密访问等已有能力的操作规则。
- 具体设计、技术选型及开发分工。

照片记录仍为已确认首版保留。上一轮提出的其他首版和组织方案没有因清理需求而自动通过。备份与恢复、单条私密及 AI 继续后置；应用锁、备份提醒等维持暂缓。

## 怎样审核与维护

- 每轮讨论五个完整能力组，说明用途、范围、关系与建议安排；界面与实现细节随对应阶段确定。
- 使用示例不新增需求、开发任务或上线承诺。审核时不再按生活主题重复拆出同义能力。
- 保留方向、具体范围、上线版本与设计方案分别决定。归为一组不要求所有子能力同时上线。
- 每项需求正文和现行状态只在所属能力文件维护；总统计与当前讨论位置只在本索引维护。
- 功能增删或状态变化时同步总索引、相关分期与分工；清理内容时一并移除无效引用。
- 现存编号不因目录调整而重排；后续确需独立新增的能力先说明独特价值。
- 导航使用 Markdown 文件链接与标题链接；文件名或标题变更时同步检查引用。
